# Filme oficial de abertura

Coloque aqui o vídeo aprovado do Kling AI com o nome `layal-hero.mp4`.

O arquivo não está incluído nesta demonstração. Até sua chegada, a home apresenta somente a composição conceitual já identificada. Não existe vídeo fictício nem requisição a um MP4 inexistente.

Use MP4 compatível com navegadores (H.264), sem áudio necessário à compreensão. Prefira um arquivo otimizado para celular. Após adicionar/substituir o arquivo, execute novamente o build/deploy para que a home detecte sua presença.

O vídeo recebe uma camada escura para leitura dos textos, reproduz sem som e pausa quando o visitante prefere movimento reduzido. A página continua utilizável se o navegador impedir a reprodução automática.
