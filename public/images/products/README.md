# Fotografias oficiais dos perfumes

Coloque aqui somente fotografias fornecidas e aprovadas pela Layal. Não há fotografias fictícias ou substitutas nesta pasta.

Nome padronizado: `marca-perfume-volume-principal.jpg` (também JPEG, PNG ou WebP), minúsculo, sem acentos/espaços. Associe ao ID do perfume na planilha e ao campo `photoPath` como `/images/products/nome-do-arquivo.jpg`.

Não alterar frascos, embalagens, rótulos ou cores. Sem foto, usar `photoPath: null`; a interface apresenta o espaço reservado identificado. Consulte `docs/CATALOGO-OFICIAL.md` para o formato completo de entrega.
